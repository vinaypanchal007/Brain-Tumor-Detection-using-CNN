# 🧠 Brain Tumor Detection using CNN

A deep learning project that detects the presence of brain tumors from MRI scans using a Convolutional Neural Network (CNN).

## Overview
- Binary image classification: **Tumor** vs **No Tumor**
- Trained on 253 MRI images with data augmentation to prevent overfitting
- Achieves ~84% test accuracy
- Interactive web app built with **Streamlit**

## Tech Stack
- Python, TensorFlow, Keras
- OpenCV, NumPy, scikit-learn
- Streamlit (frontend)

## Disclaimer
This tool is for educational purposes only and is not a substitute for professional medical diagnosis.
